# Glossary

Terms used in mikura docs and code. If a word is not here, do not invent a
meaning; say it is undefined.

| Term | Meaning |
| --- | --- |
| **Object** | A typed record with a required `namespace`, primary `key`, `props`, `hidden` flag, optional `action_id`, and `gen`. Identity is `(namespace, kind, key)`. |
| **Generation** (`gen`) | Monotonic version of that identity. `Store::append` bumps it. In edition 2021 the field is named `gen`; it must be renamed before an edition 2024 bump. |
| **Object log** | Append-only 4 KiB CRC pages. Authority for identity. [ADR 0001](decisions/0001-paged-log.md). |
| **Backup** | The committed pages of the object log up to a commit point, plus the log checkpoint when taken at or before it, copied while the host serves (`mikura-host backup`, ADR 0037). `verify` checks it; `restore` writes a new log up to a restore point. The sidecar is a rebuildable projection, never copied. After optional compact, the checkpoint holds Action ids the shortened log no longer contains. There is no backup RPC. |
| **Restore point** | `mkrp1:<commit point>:<page crc>`: a commit point tied to one log's history by the CRC of the page that ends it (ADR 0037). |
| **Superblock** | Page 0 of the log. Holds CRC32, magic `MIKURAV2`, page size, and `committed_pages`. `MIKURAV1` fails closed until migrated (ADR 0030). |
| **Committed range** | Pages `1..=committed_pages`. Rebuild reads this range, or only the tail after a valid log checkpoint. Extra bytes after it are not authority. |
| **Log checkpoint** | Checksummed snapshot `{log}.ckpt` (`MKCKPT01`) of live identity, generations, join maps, and the Action-id catalog at a committed page. `{log}.ckpt.prev` is the previous complete file. Open starts from the newest valid checkpoint and replays only the tail. A torn current file falls back to previous or full replay. Optional `Store::compact_to` writes live generations to a new log. The 4 KiB page layout does not change. [ADR 0034](decisions/0034-log-checkpoints.md). |
| **Projection** | Derived index (live maps, hop/join maps). May be deleted and rebuilt from the log. Never recovery material. |
| **Sidecar** | A projection file next to the log (`{log}.joins`, magic `MKJOIN05`). Per-namespace interned property pairs plus slim identity including optional Action id; hop/sum indexes omit hidden rows; schema-named last-hop sums persist as parent rollups. Dirty commits may add `{log}.joins.delta` (`MKJOIN5D`). Checksummed; deletable; rebuilt from a `MIKURAV2` log. Old `MKJOIN04` and earlier fail closed until deleted. [ADR 0004](decisions/0004-slim-join-maps.md), [ADR 0005](decisions/0005-current-object-load.md), [ADR 0006](decisions/0006-action-provenance.md), [ADR 0010](decisions/0010-last-hop-measures.md), [ADR 0028](decisions/0028-store-namespace.md). |
| **Namespace** | Required identity prefix on every object, read, evaluate, hop, aggregate, overlay, and Action. Missing or unknown fails closed. The first write creates it. Not a principal. [ADR 0028](decisions/0028-store-namespace.md). |
| **Load** | `Store::load(namespace, kind, key, acl)` returns the live `ObjectRecord`. Denied properties are omitted. Missing or unknown namespace fails closed. Missing identity fails closed. Hidden records are returned and stay out of join maps. |
| **Hidden** | Tombstone of an identity. Evaluate and join maps omit it; `load` still returns it. Recreate is a later visible append of the same `(namespace, kind, key)`. [ADR 0008](decisions/0008-type-link-delete.md). |
| **Schema descriptor** | Clerk-authored kind/property/link rules persisted as `mikura.schema/<kind>` (`properties`, `required`, `links`, optional `sums`, optional `types`, optional `conflict`, optional `version`). `sums` names last-hop measure properties already in `properties`. `types` declares boolean, integer, timestamp, or decimal encodings. `conflict` is `user` or `newest` overlay merge; optional `conflict_properties` overrides per property; `conflict_time` names the source timestamp for `newest`. `version` is monotonic per kind (absent is 1). Recast, rename, retarget, and drop need `migrate_cast` / `migrate_rename` / `migrate_retarget` / `migrate_drop`. Visible writes of that kind fail closed on unknown, missing required, empty outgoing-link keys, or non-canonical typed values. `Store::load` is the current version; `Store::load_at_schema` names an earlier one; `Store::load_with_schema` applies a supplied check. Not a query language. [ADR 0008](decisions/0008-type-link-delete.md), [ADR 0010](decisions/0010-last-hop-measures.md), [ADR 0012](decisions/0012-typed-values.md), [ADR 0013](decisions/0013-schema-evolution.md), [ADR 0032](decisions/0032-overlay-conflict-strategy.md), [ADR 0035](decisions/0035-versioned-schema-migration.md). |
| **Canonical property encoding** | Unique UTF-8 form of a declared non-string scalar in `props` (`true`/`false`; canonical `i64`; UTC `YYYY-MM-DDTHH:MM:SS.sssZ`; decimal with descriptor scale). Invalid input fails closed. `Store::load` still returns the stored bytes. [ADR 0012](decisions/0012-typed-values.md). |
| **Object-set** | A request to filter / load / hop / aggregate objects. There is no query language. Evaluate hops in either join direction, then count/sum, plus optional exact-match on visible roots (`EvaluateRequest.filter`) or a composed predicate tree (`eq` / `neq` / `range` / `missing` / `and` / `or` / `not`, optional after each hop). `object_bound` > 0 also returns the distinct matching objects, fail-closed if the set is larger. `sort` plus `page_size` returns snapshot pages; the cursor binds restriction, query, and the live writer stamp. Extra aggregates stay out ([ADR 0018](decisions/0018-aggregation-semantics.md)). [ADR 0015](decisions/0015-composable-object-sets.md). |
| **Hop** | Join along a named property. Default: parent `key` to child `props[join_property]`. `incoming: true` follows `props[join_property]` on the frontier to `far_kind`. Evaluate hops a frontier of identities tagged by originating root, then folds the last hop's count/sum without storing every leaf path. |
| **Envelope** | A published measurement with fixture size, hardware, hold/miss, and the question asked. A miss is not an engine pick. |
| **Hold / miss** | Envelope result: the target latency or correctness check passed (hold) or failed (miss). |
| **Fail closed** | On checksum mismatch, missing committed pages, ACL denial of an aggregate, or a schema violation: return an error. Do not guess. Load omits denied properties instead of fabricating them. |
| **Property ACL** | v1: in-process deny list of `(kind, property)`. Load / host `load` omit those keys (never `""`). Evaluate of a denied aggregate returns `AclError::Denied`. The wire does not list denied names. Not a principal. |
| **Action** | Governed edit in the product sense. `apply_action` appends a new visible generation and stores the clerk-assigned Action id ([ADR 0006](decisions/0006-action-provenance.md)). A repeated id with the same body is a replay ([ADR 0011](decisions/0011-action-id-retry-key.md)). The same unique-id rule covers `apply_overlay` patches ([ADR 0019](decisions/0019-overlay-retry-and-mutation-boundaries.md)) and ingest append ([ADR 0025](decisions/0025-ingest-action-id-uniqueness.md)). |
| **Compute backend** | Pluggable evaluate implementation. `LocalCompute` runs in-process. `SparkCompute` always returns unsupported. |
| **Dual-read** | Compare a projection answer to a log replay (or a slower oracle) on the same fixture. |
| **Clerk / warehouse** | Control plane stores who/policy/receipts (clerk). mikura stores objects (warehouse). |
| **mikura-ingest** | Write orchestrator crate in this repo. Depends on `mikura` only. Clerk maps records; this crate merges by identity and appends. |
| **Edit overlay** | Admitted named-property patch for one identity. The last accepted patch persists as `mikura.overlay/{kind}/{key}`. A later visible source write keeps those keys and takes unedited keys from source unless the kind descriptor selects `newest` ([ADR 0009](decisions/0009-refresh-safe-edit-overlay.md), [ADR 0032](decisions/0032-overlay-conflict-strategy.md)). `apply_action` stays a whole-record replace. `MergeIngest` last-wins in the cycle, then appends as source writes (overlay merges). |
| **Snapshot changelog** | Diff of two source snapshots by `(namespace, kind, key)` into upserts and hides. A changed Action id is a payload change. Empty diff appends nothing. Output is source input to merge. Resume after failure re-runs that diff; changelog source offsets stay with the clerk ([ADR 0020](decisions/0020-resumable-source-reconciliation.md)). |
| **Stream bound** | Max outstanding uncommitted records on `StreamIngest` or `StreamApply`. Excess `push` / `apply` fails closed. |
| **Stream apply** | Ordered per-key ingest of a named source. Duplicate and older offsets skip without a new generation. Last committed offset persists as `mikura.source/<source>`. Resume after reopen reads that row. Visibility target is seconds on the product-loop fixture ([ADR 0031](decisions/0031-ordered-stream-apply.md)). |
| **mikura-host** | Single-process host. JSON RPCs over `Store` (`ingest_batch`, stream push/flush, `apply_action`, `apply_overlay`, `hide`, `evaluate`, `load`). Required `--log`; `--bind` default `127.0.0.1:0`; `--stream-bound` default 8. Loopback bind is unauthenticated unless `--bearer` is set. Non-loopback bind requires a clerk-owned bearer on every RPC ([ADR 0007](decisions/0007-host-bearer.md)). A line over `--request-bound` is `RequestBound`. Assembling the request line past `--request-timeout-ms` is `RequestTimeout`. After a complete line, evaluate and ingest run to completion. Concurrent snapshot readers, one exclusive writer, per-namespace fair share ([ADR 0040](decisions/0040-concurrent-host-readers.md), [ADR 0021](decisions/0021-bounded-host-execution.md)). |
| **Spike** | Throwaway harness under `spikes/`. A spike may use JSONL or SQLite as a *vehicle*. That vehicle is not mikura’s store of record. |
